# Extra scripts for user text

Prepared subsets used by `ui/tools/gen_intl_fonts.py` (see that script for how they are made):

- `NotoSansThai-Disco.ttf` - Noto Sans Thai, Thai block, tone marks moved above the upper vowels.
- `NotoSans-Vietnamese.ttf` - Noto Sans, precomposed Vietnamese letters (U+1EA0-U+1EF9).
- `NotoSansKR-KSX1001.otf` - Noto Sans CJK KR, the 2,350 Hangul syllables of KS X 1001.

All SIL Open Font License 1.1: Noto Sans and Noto Sans Thai `licenses/OFL-1.1-NotoSans.txt`; Noto Sans CJK is Source
Han Sans, `licenses/OFL-1.1-SourceHanSans.txt`.
