# Disc Shelf 1.0.4

Legacy standalone Navidrome browser and original-file downloader for older firmware. Disco 2.7.0 and later have a native Disc Shelf with Navidrome/SMB3 support built into mq_ui; use that instead. This 1.0.4 archive is retained unchanged in functionality for older builds and does not provide SMB3.

See [installation and configuration](../../docs/DISC_SHELF_INSTALL.md). The example configuration contains placeholders; your existing shelf.conf must be preserved and kept private. Open it from the Disco navigation circle (Disco Options > Disco Menu), All apps or Shortcuts. The included corresponding source is disc-shelf-1.0.4-source.tar.gz.
