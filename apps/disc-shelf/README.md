# Disc Shelf 1.0.4

Standalone Navidrome browser and original-file downloader, included as an optional add-in with diskOS Disco. This is the exact binary previously tested by the owner. It is not embedded in mq_ui.

See [installation and configuration](../../docs/DISC_SHELF_INSTALL.md). The example configuration contains placeholders; your existing shelf.conf must be preserved and kept private. Open the app from All apps or add it to Shortcuts. The included corresponding source is disc-shelf-1.0.4-source.tar.gz.
