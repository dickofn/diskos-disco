# diskOS Disco! 2.0

**Install from Windows.** diskOS Disco! for Windows takes you from a Windows PC to a Disc running Disco! in four
pages, with no terminal and no Linux knowledge, and makes your SD updates afterwards.

> [!NOTE]
> **Already on 1.4.1 or later?** The interface part of 2.0 is an ordinary SD update, no reflash ([guide](../UPDATING.md)).
> **Coming from 1.4.0 or older?** Reflash once with your existing keys: from Linux as before, or with the Windows app
> (choose "Use my existing keys folder").

## diskOS Disco! for Windows

Download **diskOS-Disco-for-Windows.zip** from this release, extract it and run `diskOS-Disco.exe`.
[Full guide](../WINDOWS.md).

1. **Check:** Windows 11 (64-bit), virtualization, WSL, the usbipd-win USB bridge, disk space and pending restarts.
   Anything missing gets a plain explanation and a button that fixes it or opens the right installer.
2. **Prepare:** one click sets up diskOS's own small Linux environment (about 150 MB) with the installer and its tools
   already inside. It's private to diskOS, never touches other WSL setups, and can be removed in one click.
3. **Install:** choose FiiO's V2.57 firmware ZIP, create your update keys (or use your existing ones), connect the Disc
   with Volume Down held, and install. The app finds and connects the Disc, runs the diskOS installer, keeps the PC awake
   and keeps a copy of the backup of your Disc's original system in a normal Windows folder.
4. **Update:** downloads the latest release (checked against its checksums), signs it with your keys and writes the
   `diskos-update` folder to your SD card.

Also: a "Good to know" page at every start (what this is and isn't), an About page with thanks, and Copy report on
every page for easy help requests. The app is free, needs no administrator rights itself, and isn't code-signed yet
(Windows may say "protected your PC": More info, Run anyway).

## Interface

- **No more false "Couldn't start playback".** A big playlist can take the player a few seconds to load; the warning
  came just before the music did. It now waits longer, and only appears if nothing plays at all.

## Everything else

The interface is otherwise 1.5.0's: [Boomshine](../DISCO_TOUR.md#boomshine), apps in the navigation circle with their
own landing pages, and the expanded Disc Shelf guide. Disc Shelf 1.0.4 and Album Roulette 1.3.1 are unchanged and
installed separately.

## Install

- **Windows:** diskOS-Disco-for-Windows.zip ([guide](../WINDOWS.md)).
- **Linux:** the installer in the source download or repository ([README](../../README.md#install)).
- **SD update:** `mq_ui` from this release, signed with your keys ([guide](../UPDATING.md)), or the Windows app's
  Update page.
