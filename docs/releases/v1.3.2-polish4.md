# 1.3.2-polish4 - development candidate

Includes all pending dev navigation gestures, first-use hints and configurable
Disco Quick Settings. Stable main remains 1.3.1; device acceptance is pending.

## Quick Settings

Display > Disco Options > Quick Settings > Style: Current / Arc. Arc is the
new default; saved settings remain intact. Choose Arc explicitly if needed.
Items uses the Disco Menu editor: add/remove/reorder up to eight actions.
Wi-Fi/BT retain their inner positions; other actions follow editor order on
six evenly spaced outer targets. All Arc buttons are 66px. Left mirrors the
screen. The disc and brightness/battery/playback controls are preserved.
Current supports all eight actions too, using compact rows when needed.

Hold radios to open settings; hold another action to see its name. Wi-Fi/BT
show On/Off (pending dots during Bluetooth startup). Rescan asks confirmation.
No additional periodic timer or expensive animation is introduced.

## Device test with signed SD update

Use your existing owner keys on your computer; never share private keys.
From the repository, sign the supplied candidate:

```sh
sh ui/tools/owner-keys/diskos-sign.sh /absolute/path/to/mq_ui 1.3.2-polish4 /absolute/path/to/diskos-keys
```

Copy the entire generated diskos-update directory to the SD root. Eject safely,
insert the card and follow the UI's update prompt. The existing signature,
trial and rollback checks remain intact. Accept/Keep the trial before restarting.
Do not replace the UI over SSH. On failure inspect:

```sh
ssh root@192.168.178.63 'cat /usr/data/updates/last_result'
```

Check Arc on Right/Left and dark/light, radio state and hold actions, item edits,
eight items in Current, playback and brightness, hints and open-menu gestures.

## Validation and payload

Native LVGL tests pass for both sides: bounds/non-overlap, radio interaction,
all selectable icons, parsing, empty layouts, item editing/persistence/failure,
navigation gestures and first-use hints. Static MIPS32r2/FP64/NaN2008 build
checks pass. payload/mq_ui.build.json identifies the matching source and binary.
These checks do not establish device performance or battery consumption.
Standalone apps and stable release tags are unchanged.
