# diskOS Disco! 2.5.0 — Big. Bold. Squash. 🎃

Squash takes the spotlight: a warm, readable theme built around big text and touch playback. Null and the existing themes keep their own look, settings and shared features.

## Meet Squash

- **Big, bold, readable:** Nunito Bold by default. Original and Inter Semibold use the same fixed 36/32/28 px title/artist/album hierarchy. Long metadata scrolls three times on track change, then rests; choose left or centred text.
- **Touch playback:** tap track text for actions and Mood; double-tap to play/pause; swipe right for next or left for previous. The matching action icon flies out of D!.
- **A little planet of a launcher:** a larger 72 px D! hub opens a circular cap from the bottom. Drag through large icons, release to snap and tap to open. Double tap and Hold use your chosen actions; Hold works on the hub and the large launcher icon without firing during a drag.
- **Eight icon Quick Settings:** artwork and play/pause in the centre, clear orange active states, brightness and battery arcs with icons. Add, remove and reorder shortcuts independently per theme, including cycling playback mode.
- **Calm backgrounds:** Plain, Blur or Cover; charcoal/orange or off-white/orange. Blur uses a moderate cached image and 20% overlay; Cover retains 30%. Line or 270° arc progress, with the bottom reserved for D!.
- **Volume B:** a clean draggable bottom arc, live 0–120 value and familiar D! circle. No ± buttons or screen-wide dimmer. Tap D! or outside to close; auto-hide waits 1.8 seconds after input and pauses while dragging. Entry/exit takes 140/110 ms.
- **Finishing touches:** centred list Back arrows, matching standby text, optional independent play/pause and mode indicators beside D!, and a fix for duplicated track-time shadows. Gesture dots/arrows around the hub are removed.

## Help that helps

**Settings → Help**, directly below Battery, brings together **How to**, **First-use hints** and **Show hints again** in Squash, Disco and Null. How to presents one topic per page with large text and a bottom next-page arrow. Contextual hints explain navigation, playback gestures, seeking, radio holds, artwork, clock visibility and volume. Hint preferences and learning counters are separate for each theme.

## Null stays

Null keeps its pixel fonts, vivid palettes, artwork treatments, sliding navigation, vertical Quick Settings and choice of text or icons. The shared QS editor retains add/remove/reorder and independent saved layouts. Music and Settings stay protected in the main menu. See [Null](../NULL_THEME.md) and [the 2.4.0 notes](v2.4.0.md).

## Install

Already on 1.4.1 or later? Use an SD UI update with your existing signing key; no reflash is needed. A raw `mq_ui` is the interface payload, not a signed update. Windows: use the app’s Update page. Linux and other systems: [Updating](../UPDATING.md). See [How-to](../HOWTO.md), the [tour](../DISCO_TOUR.md), [Squash settings](../themes/squash.md) and [theme authoring](../../themes.md).

## Validation

Native LVGL renders and focused interaction checks cover fixed font sizes, independent indicators, QS editing, launcher/hold/double-tap behavior, playback gestures, volume dragging, final volume commits and dismissal. The release UI is static little-endian MIPS32r2, o32, NaN2008. No new physical-device flash, FPS or battery-life claim is made. Existing theme presentation is preserved outside the explicitly shared menu/help changes.
