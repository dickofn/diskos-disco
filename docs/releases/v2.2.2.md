# diskOS Disco! 2.2.2

An SD update from 1.4.1 or later: no reflash. [Download](https://github.com/zmd22/diskos-disco/releases/latest) ·
[changelog](../../CHANGELOG.md) · [2.2.1 release notes](v2.2.1.md)

- **A surprise!**
- **Listening Stats:** album covers show in the Wrapped bubbles again (they fall back to another track of the album,
  then the small thumbnail), each bubble has its own letter, and letters in any script draw properly.
- **Listening Stats:** small < > arrows at the ends of the Week / Month / Year arc show it can be swiped.

## Install

Windows: the Windows app's **Update** page. Other systems: [Updating](../UPDATING.md).
