# diskOS Disco! 2.2.1

An SD update from 1.4.1 or later: no reflash. [Download](https://github.com/zmd22/diskos-disco/releases/latest) ·
[changelog](../../CHANGELOG.md) · [2.2.0 release notes](v2.2.0.md)

Fixes only.

- **USB DAC** plays again on the latest firmware (it was silent).
- **Listening Stats** no longer merges restarts of the same song into one longer play.
- **SongSphere** keeps the placements from the separate app safe while moving them, and no longer freezes on very
  large libraries.
- **Album Roulette** tidies up after itself when you leave.
- **App icons:** unusual BMP files fall back to the letter instead of showing wrong colours.

## Install

Windows: the Windows app's **Update** page. Other systems: [Updating](../UPDATING.md).
