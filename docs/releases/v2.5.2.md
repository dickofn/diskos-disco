# diskOS Disco! 2.5.2

A clearer first start, a more comfortable Squash interface, and a lighter Album Roulette.

## First start

Fresh installs open in **Disco, dark appearance**, with **hints On**, a **straight progress bar**, and **no track-number prefix on Music**. Saved choices and legacy theme migrations are preserved.

## Squash

- Wi-Fi and Bluetooth have larger, centred logos, larger Scan/power controls, and more readable network/device names and status text.
- Working mode and Shortcuts share the same pill rows, readable labels and larger headers. All five modes stay visible without scrolling, with a smaller Back gesture gutter.
- The shared Accent Colour option shows Disabled and explains that Squash uses its own palette.

## Album Roulette

- Again and Exit sit beside the white Play ball. Album and artist names use larger text and wrap to two lines; exceptionally long names receive an ellipsis after the second line.
- Covers are stored at 224 × 224 instead of 268 × 268, reducing cover pixel storage by about 30%, while retaining their displayed size and animation timings.
- Covers decode directly to their storage size through the built-in serialised artwork decoder, with a 4–16 MiB allocation cap and cancellation checked before decoding starts. A raw UI update does not require replacing the player's read-only artwork helper.
- The preparation-wheel bitmap is released when spinning begins. After leaving, covers are detached and released once the loader has finished and the outgoing screen is hidden.

## Track popup and Library seeking

- Popup metadata uses full-line label heights: long artist names scroll horizontally, without a vertical loop caused by a too-small text box.
- The unselected favourite icon is white. Selected appearance and behaviour are unchanged.
- The letter wheel has an opaque ring behind A–Z, matching the centre control. The surrounding overlay remains half-transparent; the one-second release deadline stays unchanged.

## Website

Orange and black, restrained rainbow accents, the firmware's Monoton Disco! lettering,. Desktop chapters pin briefly during ordinary scrolling; mobile, short viewports and reduced-motion settings use normal flow. Existing theme previews, newcomer guidance and tour links remain.

The installation docs now include a [macOS guide](../MACOS.md), with links to upstream 1.2.0 Apple Silicon flash tools and the Intel source-build route.

## Build and test status

Rebuilt with the repository's prebuilt GCC 11.2.0 / musl 1.2.6 MIPS32r2 FP64 NaN2008 toolchain. Native LVGL interaction checks, decoder allocation/cancellation checks, config/playback/file-operation regressions, artwork responsiveness and website logic checks passed. See `docs/performance/2.5.2-test-notes.md` for scope and limitations. Physical-device validation remains pending. The supplied raw mq_ui is intended for the owner's test before publishing.
