# diskOS Disco! 2.5.3

Null gets a new Matrix colour scheme: bright white and vivid green on black. Choose it in Display > Null Options > Palette.

- Null Accent Colour is disabled with an explanation; its palette controls shared accent colours too.
- Less repeated menu, Quick Settings and scrollbar styling work. Menu inertia, animation timing and list scrolling behaviour are retained.
- Null navigation slider hit testing follows the slider's actual position.
- Shortcuts and Working mode share five fixed rows in Null and Squash. Null keeps its square controls and pixel fonts; headers stay inside the round display.
- Swiping to Shortcuts now shows feedback like Back, with a Shortcuts icon, across all themes.
- History records tracks while the screen is off. Most Played and Recently Played retain existing data, and their rows use the same swipe guard as normal songs. Missed historical plays cannot be reconstructed.

Based on public 2.5.2. The abandoned experimental DiskOS migration/return feature is not included. There is no first-boot settings reset or migration backup process.

Native LVGL and configuration checks are documented in docs/performance/2.5.3-null-review.md. Physical Disc testing and performance measurements remain pending. No measured frame-rate or memory improvement is claimed.
