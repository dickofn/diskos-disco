# diskOS Disco! 2.4.0

A complete Null theme and a round of usability improvements for Disco and Null.

- **Meet Null:** pixel typography, vivid palettes, black/darkened/pixelated artwork backgrounds, sliding navigation and a vertical Quick Settings panel. Choose text or icons and four Music font combinations, including large dot-matrix titles with terminal details.
- **Quick Settings, your way:** add, remove and reorder items independently in each theme. Null honours the saved selection exactly, with eight available slots and its own artwork and transport controls.
- **Clearer settings:** larger centred selectors and explanations, better touch targets and less overlapping text. Null remains right-handed; the retained Side option explains that it is disabled.
- **Help where you need it:** Help sits below Battery in both themes, with one-topic How to pages, contextual gesture hints and independent first-use hint preferences.
- **Calmer scrolling:** only the focused library row scrolls. Music titles, artists and albums scroll three times after a track change, then rest.
- **More readable standby:** Disco has larger track text below the centre, larger weather information and a clock with more room beneath the status icons.
- **Finishing touches:** themed Bluetooth, Wi-Fi and track information screens, matching bars and transport controls, clearer Null battery/brightness strips and a restored back swipe on the track popup.
- **For theme authors:** themes.md documents shared behaviour, theme-specific settings and strict preservation of existing themes' appearance and functionality.

## Install

An SD update from 1.4.1 or later: no reflash. Windows: use the Windows app's **Update** page. Other systems: see [Updating](../UPDATING.md). Download **mq_ui** for the interface, or the complete ZIP for the interface, apps and installation instructions. GitHub also provides source archives for this tag.

## Validation

Focused native rendering and interaction checks passed, including Quick Settings editing in Disco and both Null layouts. The device binary is verified as static MIPS32r2, FP64, NaN2008. Physical Disc testing remains pending.
