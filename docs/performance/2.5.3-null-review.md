# 2.5.3 Null work in progress

Baseline: public main 4ca0a0f (2.5.2). No experimental migration or restore machinery.

Implemented:
- History tracking runs after normalized playback state, independently of screen-off visual refresh. Existing UI entry point remains deduplicated.
- Null custom Accent is visibly disabled with a tap explanation; shared accent users use the selected Null palette.
- Matrix palette: white #FFFFFF, green #39FF14, black, dark-green borders and pressed keyboard keys. Previous palette indices remain unchanged.
- Null menu skips painting unchanged position/press state. Cubic settle uses multiplication with the same timing; inertia unchanged.
- Slider hit testing follows the actual rail position instead of a fixed screen Y coordinate.
- Null scrollbar and QS avoid repeated unchanged colour/style writes.
- Shortcuts and Working mode share fixed five-row geometry in Squash and Null, with theme-specific fonts and treatment. Null headers are larger.
- Skip redundant forced Null restyling for those two screens; screen manager still styles new widgets normally. Other screens retain conservative restyling because refresh code can modify existing widgets.
- Shortcuts swipe feedback mirrors Back feedback, using LV_SYMBOL_BARS; uses existing gesture acceptance threshold and timing and hides on release. Available across all themes.

Validation is native LVGL only; no device benchmarks or measured frame-rate claims.
Native renderer: Matrix Music/Library/QS/Working mode/Shortcuts/EQ render; focused Null gestures/volume and fixed-row layout checks pass. Shortcut feedback renders under Disco, Null, Squash, Ring and Braun. Theme policy and whitespace checks pass.
The legacy REVIEW_NULL pointer suite gets through menu drag and selection, then fails at an obsolete QS Wi-Fi touch coordinate (120,42); current QS puts its clock there. Do not report this suite as passing.

Deferred: broad replacement of forced screen restyling, arbitrary changes to momentum/speed, changes to hidden-label animations. These need more coverage to avoid UI regressions.
